# v40 Hindsight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v40 "Hindsight": a History panel where every undo step has a name and a picture, can be jumped to or peeked at, plus saved Versions that outlive the undo list, plus the Looks follow-ups (chip previews, per-shot looks in the Roll, Design Agent look and light / dark tools).

**Architecture:** `src/state/history.js` keeps one small record per state (`{ id, label, at }`) paired with its `past` / `future` snapshot stacks, so steps keep their identity through undo, redo and jumps. Step names come from a pure diff of two snapshots (`src/state/history-labels.js`), so the 206 existing `saveStateToHistory()` calls need no edits; a few call sites pass an explicit label. Thumbnails swap a snapshot into `state` (`withSnapshot`), run the normal `renderInto` export passes offscreen and scale down. Versions are named snapshots in a new `state.versions` key, saved with the project (schema 24 -> 25), never part of undo.

**Tech Stack:** Vanilla JS + Vite, Canvas 2D, Node `assert` tests in `scripts/regression-tests.mjs`, ESLint + knip via `npm run check`.

## Decisions made in this plan

1. **Labels are inferred, not hand-written.** Labeling all 206 call sites would touch 52 files and drift. `describeChange(before, after)` names a step from the snapshot diff ("Added arrow", "Background and frame", "Flipped to dark"). Only places the diff cannot see (a new screenshot, AI edits, templates, the Design Agent turn, Looks, Reset) pass a label.
2. **A label names the state a step leads to.** `saveStateToHistory('Look: Matte')` is called *before* the mutation, so the label belongs to the new current state, which is the one the look produces.
3. **Thumbnails use the current screenshot.** Images are not in undo snapshots, so jumping back keeps today's screenshot; the thumbnails show exactly what a jump would give. When the screenshot changes, every thumbnail is redrawn.
4. **Versions save the design, not the screenshot**, the same as undo, and never carry the Roll (shot images live outside the snapshot). The panel says so in one line.
5. **Per-shot looks reuse the Roll's scope switch.** `imageFilters` and `colorTools` join `ROLL_OVERRIDE_FIELDS`. This reverses v38's "a grade styles the whole roll": in "This shot" scope (the default) a grade edit now stays with the open shot, which is what the scope switch already promises. "Whole roll" scope still grades every shot. The scope hint text is updated to say so.
6. **Dropped: "Use a step as Before".** Peek covers the same need without an image re-encode.

## Known issue left alone

History is not cleared on page switches, so undo after switching pages restores the previous page's design onto the current one. That is v32 behavior, not new, but the panel makes it visible. Task 1 adds `clearHistory()` so a follow-up can call it from `pages.js` `switchTo()`. Out of scope here because it changes undo across pages for every user.

```js
export function saveStateToHistory(label) {
  endPeek();
  const usePending = pendingEdit && changeTarget && pendingEdit.target === changeTarget;
  history.past.push(usePending ? pendingEdit.snap : snapshot());
  steps.past.push(steps.current);
  steps.current = newStep(typeof label === 'string' ? label : null);
  pendingEdit = null;
  if (history.past.length > history.maxSize) {
    history.past.shift();
    steps.past.shift();
    history.trimmed = true;
  }
  history.future = [];
  steps.future = [];
  emit();
}

export function undo(rerender) {
  endPeek();
  pendingEdit = null;
  if (history.past.length === 0) return;
  history.future.push(snapshot());
  steps.future.push(steps.current);
  applySnapshot(history.past.pop());
  steps.current = steps.past.pop();
  rerender && rerender();
  emit();
}

export function redo(rerender) {
  endPeek();
  pendingEdit = null;
  if (history.future.length === 0) return;
  history.past.push(snapshot());
  steps.past.push(steps.current);
  applySnapshot(history.future.pop());
  steps.current = steps.future.pop();
  rerender && rerender();
  emit();
}

// v40 — every state, oldest first. The live state's snap is taken now; the
// future is a stack, so it is read backwards.
export function historyTimeline() {
  const out = history.past.map((snap, i) => ({ step: steps.past[i], snap, index: i, current: false }));
  out.push({ step: steps.current, snap: snapshot(), index: out.length, current: true });
  for (let i = history.future.length - 1; i >= 0; i--) {
    out.push({ step: steps.future[i], snap: history.future[i], index: out.length, current: false });
  }
  return out;
}

// v40 — go straight to a step (an index from historyTimeline). Walks the
// stacks one step at a time so snapshots and records stay paired, but applies
// state, re-renders and notifies listeners once.
export function goToStep(index, rerender) {
  endPeek();
  pendingEdit = null;
  const cur = history.past.length;
  const total = cur + 1 + history.future.length;
  if (!Number.isInteger(index) || index < 0 || index >= total || index === cur) return false;
  let snapNow = snapshot();
  while (history.past.length > index) {
    history.future.push(snapNow);
    steps.future.push(steps.current);
    snapNow = history.past.pop();
    steps.current = steps.past.pop();
  }
  while (history.past.length < index) {
    history.past.push(snapNow);
    steps.past.push(steps.current);
    snapNow = history.future.pop();
    steps.current = steps.future.pop();
  }
  applySnapshot(snapNow);
  rerender && rerender();
  emit();
  return true;
}

export function clearHistory() {
  endPeek();
  pendingEdit = null;
  history.past = [];
  history.future = [];
  history.trimmed = false;
  steps.past = [];
  steps.future = [];
  steps.current = newStep();
}

// v40 — look at a step without changing history. Its values are copied into
// state; the live objects are kept by reference and put back exactly, so
// runtime fields (roll.activeShot, timeline._driving) survive. state.image and
// state.lastImageRect ride along: a crop rebuild or a render can replace them.
function swapIn(snap) {
  const saved = { image: state.image, lastImageRect: state.lastImageRect };
  for (const k of Object.keys(snap)) saved[k] = state[k];
  Object.assign(state, JSON.parse(JSON.stringify(snap)));
  return saved;
}

export function withSnapshot(snap, fn) {
  const saved = swapIn(snap);
  try { return fn(); } finally { Object.assign(state, saved); }
}

let peeking = null;

export function peekStep(index, rerender) {
  endPeek();
  const entry = historyTimeline()[index];
  if (!entry || entry.current) return false;
  peeking = swapIn(entry.snap);
  rerender && rerender();
  return true;
}

export function endPeek(rerender) {
  if (!peeking) return false;
  Object.assign(state, peeking);
  peeking = null;
  rerender && rerender();
  return true;
}

export function isPeeking() { return !!peeking; }
```

```js
  annotations: { noun: (a) => TYPE_NAMES[a && a.type] || 'annotation', many: 'annotations' },

const TEXT_MAX = 24;
const same = (a, b) => JSON.stringify(a) === JSON.stringify(b);
const humanize = (k) => {
  const s = k.replace(/([a-z0-9])([A-Z])/g, '$1 $2').toLowerCase();
  return s.charAt(0).toUpperCase() + s.slice(1);

const nameOf = (k) => NAMES[k] || humanize(k);

function listChange(key, before, after) {
  const spec = LISTS[key];
  const a = Array.isArray(before) ? before : [];
  const b = Array.isArray(after) ? after : [];
  const idsOf = (list) => new Set(list.map((x) => x && x.id));
  if (b.length > a.length) {
    const n = b.length - a.length;
    if (n > 1) return `Added ${n} ${spec.many}`;
    const had = idsOf(a);
    return `Added ${spec.noun(b.find((x) => !had.has(x && x.id)) || b[b.length - 1])}`;
  }
  if (b.length < a.length) {
    const n = a.length - b.length;
    if (n > 1) return `Deleted ${n} ${spec.many}`;
    const has = idsOf(b);
    return `Deleted ${spec.noun(a.find((x) => !has.has(x && x.id)) || a[a.length - 1])}`;
  }
  const i = b.findIndex((x, j) => !same(x, a[j]));
  return `Edited ${spec.noun(b[Math.max(0, i)])}`;
}

  textOverlay(a, b) {

    if ((a.content || '') === (b.content || '') || !b.content) return null;
    const t = String(b.content).replace(/\s+/g, ' ').trim();

};

export function describeChange(before, after) {
  if (!before || !after) return 'Edit';
  const keys = Object.keys(after).filter((k) => !IGNORE.has(k) && !same(before[k], after[k]));
  if (!keys.length) return 'Edit';
  if (keys.length === 1) {
    const k = keys[0];
    return (SPECIAL[k] && SPECIAL[k](before[k], after[k])) || nameOf(k);
  }
  const names = [...new Set(keys.map(nameOf))];
  if (names.length === 1) return names[0];
  if (names.length === 2) return `${names[0]} and ${lower(names[1])}`;
  return `Changed ${names.length} settings`;
}
```

```js
// v40 — Hindsight: saved versions. A version is a named copy of one undo
// snapshot (the design, not the screenshot) that stays when the undo list moves
// on and travels with the project, per page. DOM-free (the tests import it).

export const MAX_VERSIONS = 12;
const NAME_MAX = 40;
const THUMB_RE = /^data:image\/(png|jpeg|webp);base64,[A-Za-z0-9+/=]+$/;

export function cleanName(name, fallback = 'Version') {
  return String(name ?? '').replace(/\s+/g, ' ').trim().slice(0, NAME_MAX) || fallback;
}

// A version never carries the Roll: shot images live outside the snapshot, so
// an old roll could point at shots that are gone.
function versionSnap(snap) {
  const { roll, ...rest } = snap || {};   // eslint-disable-line no-unused-vars
  return JSON.parse(JSON.stringify(rest));
}

export function makeVersion({ id, name, at, snap, thumb }) {
  return {
    id: String(id),
    name: cleanName(name),
    at: Number.isFinite(at) ? at : Date.now(),
    snap: versionSnap(snap),
    thumb: typeof thumb === 'string' && THUMB_RE.test(thumb) ? thumb : null,
  };
}

// migrateSnap runs the design migrations on each saved snapshot, so a version
// saved today still restores after a later schema bump.
export function normalizeVersions(list, migrateSnap = (s) => s) {
  if (!Array.isArray(list)) return [];
  const out = [];
  for (const v of list) {
    if (out.length >= MAX_VERSIONS) break;
    if (!v || typeof v !== 'object' || !v.id) continue;
    if (!v.snap || typeof v.snap !== 'object' || Array.isArray(v.snap)) continue;
    out.push(makeVersion({ ...v, snap: migrateSnap(versionSnap(v.snap)) }));
  }
  return out;
}

export function ensureVersionsDefaults(design, migrateSnap) {
  if (design) design.versions = normalizeVersions(design.versions, migrateSnap);
  return design;
}
```

```js
// v40 — Hindsight: saved versions. "Save as version" keeps the current design
// under a name in state.versions (per page, saved with the project, at most
// MAX_VERSIONS). Restoring one is a normal undo step. A version holds the
// design, not the screenshot, the same as every undo step.
import { state } from '../state/state.js';
import { el } from '../ui/elements.js';

export function saveVersion() {
  if (state.mode !== 'single') { showNotification('Versions work in Single mode.', 'error'); return; }
  if (list().length >= MAX_VERSIONS) { showNotification(`You can keep ${MAX_VERSIONS} versions per page. Delete one first.`, 'error'); return; }
  openField({
    label: 'Name this version', value: `Version ${list().length + 1}`, ok: 'Save',
    onOk: (name) => {
      if (list().length >= MAX_VERSIONS) return;
      const snap = currentSnapshot();
      commit([...list(), makeVersion({ id: newId(), name, at: Date.now(), snap, thumb: thumbOf(snap) })]);
      showNotification(`Saved "${cleanName(name)}".`, 'success');
    },
  });
}

export function restoreVersion(id) {
  const v = list().find((x) => x.id === id);
  if (!v) return;
  saveStateToHistory(`Version: ${v.name}`);
  applySnapshot(JSON.parse(JSON.stringify(v.snap)));
  ensureCompareImage(state.compare && state.compare.beforeSrc).then(() => render());
  window.__motionStudioRefresh?.();
  render();
  showNotification(`Back to "${v.name}". Undo to return.`, 'success');
}

function renameVersion(id) {
  const v = list().find((x) => x.id === id);
  if (!v) return;
  openField({
    label: 'Rename version', value: v.name, ok: 'Rename',
    onOk: (name) => commit(list().map((x) => (x.id === id ? { ...x, name: cleanName(name, x.name) } : x))),
  });
}

function deleteVersion(id) {
  const before = list();
  const i = before.findIndex((x) => x.id === id);
  if (i < 0) return;
  const gone = before[i];
  commit(before.filter((x) => x.id !== id));
  showNotification(`Deleted "${gone.name}".`, 'success', {
    action: {
      label: 'Undo',
      run: () => {
        const now = list();
        if (now.some((x) => x.id === gone.id) || now.length >= MAX_VERSIONS) return;
        const next = now.slice();
        next.splice(Math.min(i, next.length), 0, gone);
        commit(next);
      },
    },
  });
}

export function renderVersions() {
  lastList = state.versions;
  if (!el.versionsList) return;
  const vs = list();
  if (el.versionsEmpty) el.versionsEmpty.hidden = vs.length > 0;
  el.versionsList.innerHTML = vs.map((v) => {
    const id = escapeHTML(v.id), name = escapeHTML(v.name);
    const day = new Date(v.at).toLocaleDateString(undefined, { month: 'short', day: 'numeric' });
    return `<li class="hx-version">
      <button type="button" class="hx-jump" data-version="${id}" title="Restore ${name}">
        <span class="hx-thumb">${v.thumb ? `<img src="${v.thumb}" alt="">` : ''}</span>
        <span class="hx-label">${name}</span>
        <span class="hx-time">${escapeHTML(day)}</span>
      </button>
      <button type="button" class="hx-icon" data-version-rename="${id}" title="Rename ${name}" aria-label="Rename ${name}">✎</button>
      <button type="button" class="hx-icon" data-version-delete="${id}" title="Delete ${name}" aria-label="Delete ${name}">✕</button>
    </li>`;
  }).join('');
}

export function bindVersions() {
  el.historyVersionBtn?.addEventListener('click', saveVersion);
  el.versionsList?.addEventListener('click', (e) => {
    const del = e.target.closest('[data-version-delete]');
    if (del) { deleteVersion(del.dataset.versionDelete); return; }
    const ren = e.target.closest('[data-version-rename]');
    if (ren) { renameVersion(ren.dataset.versionRename); return; }
    const btn = e.target.closest('[data-version]');
    if (btn) restoreVersion(btn.dataset.version);
  });
  el.versionsFieldOk?.addEventListener('click', confirmField);
  el.versionsFieldCancel?.addEventListener('click', closeField);
  el.versionsFieldInput?.addEventListener('keydown', (e) => {
    if (e.key === 'Enter') { e.preventDefault(); confirmField(); }
    else if (e.key === 'Escape') { e.preventDefault(); e.stopPropagation(); closeField(); }

  // A page switch or project load replaces state.versions without a history change.
  window.__versionsCheck = () => { if (state.versions !== lastList) renderVersions(); };

}
```
