# v38 Focus: Curves, Levels and shareable Looks

## Context

v37 Exposure (the Roll) has shipped (`package.json` 37.0.0). CLAUDE.md reserves v38, codename **Focus**, for pro color tools: today Glint only has the `ctx.filter` sliders (brightness, contrast, saturation...) plus a small per-pixel pass for temperature/tint and Color Map. There are no curves, no levels, and no way to save a grade and reuse or share it. v38 adds per-channel curves and levels as a per-pixel pass that bakes into every composition path and export, plus named Looks you can save, export as a file or code, and import. It ships with the usual release notes (What's new card, editor header, changelog) written under the taste-skill, and one real site shot.

Exploration also found that `color-grade.js` `gradeImage()` reuses its output canvas in place (lines 78-80), so object-identity caches downstream (3D `ensureScreenTexture`, Compare's `imageId(after)` key) can serve stale pixels after a grade change. v38 fixes that as part of the hook, because the new pass depends on the same seam.

## Design

> Built as `render/curves-core.js`, `render/curves.js`, `features/curves-ui.js` (`bindCurves()`): `features/color-tools.js` / `bindColorTools()` already exist (the v33 eyedropper). The state key stays `colorTools`.

### State: `state.colorTools`
```js
colorTools: {
  curves: { rgb: [[0,0],[255,255]], r: [...], g: [...], b: [...] },   // control points, x/y 0..255, sorted
  levels: { rgb: { black: 0, white: 255, gamma: 1 }, r: {...}, g: {...}, b: {...} }
}
```
- Identity everywhere means no pass runs. The selected channel tab is UI-only (module variable in the UI file), not state.
- `history.js` `snapshot()`: add `colorTools`.
- `serialize.js`: add to `SERIALIZED_FIELDS`, bump `SCHEMA_VERSION` 22 -> 23, append `ensureColorToolsDefaults()` to the `normalizeProject` migrate chain.
- Second defaults layer: templates and the gallery do `Object.assign(state, snap)` without `normalizeProject`, so add a runtime backfill next to `ensureColorDefaults()` in `src/ui/bindings.js` (called from `updateUIFromState`). Add `colorTools` to `templates.js` `snapshotState()` and `compose.js` `SPEC_KEYS` so templates carry it.
- `reset.js`: reset to defaults.
- Roll: deliberately **not** in `ROLL_OVERRIDE_FIELDS` (same as `imageFilters`); a grade styles the whole roll.

### Pure logic: `src/render/color-tools-core.js` (DOM-free, `// v38`)
- `colorToolsDefaults()`, `normalizeColorTools(raw)` (clamps, sorts, dedupes x, caps points at 16, repairs bad levels; used by migration and Look import), `ensureColorToolsDefaults(design)`.
- `curveLut(points)`: monotone cubic (Fritsch-Carlson) through the points -> `Uint8Array(256)`; identity points give an identity LUT.
- `levelsLut({ black, white, gamma })` -> `Uint8Array(256)`.
- `channelLuts(ct)`: per channel R/G/B = channel levels -> channel curve -> master levels -> master curve, composed into three LUTs. `isIdentity(ct)`.
- `applyLuts(data, lr, lg, lb)` over a raw `Uint8ClampedArray` (alpha untouched).
- `encodeLook(look)` / `decodeLook(text)`: `glint-look:` + base64url JSON `{ v: 1, name, imageFilters, colorTools }`; decode validates and runs `normalizeColorTools`, returns null on junk.

### Render hook: `src/render/color-tools.js`
- `colorToolsActive()`: false when identity or `state.video.loaded` (matches `bokehActive()`/`compareActive()`; per-frame video grading is out of scope).
- `applyColorTools(src, baseKey)`: caches the base `ImageData` by `baseKey`, so a curve drag only reruns the 256-entry LUT loop, not the `drawImage` + `getImageData`. Writes a **fresh** output canvas whenever the result changes (Bokeh's rule), so 3D textures and Compare re-key. Cross-origin taint: warn once, return source.
- `color-grade.js` `gradeAndBlur`: grade -> **color tools** -> Bokeh -> (Compare in `getGradedImage`). Bokeh's `baseKey` must include the color-tools signature. Also change `gradeImage()` to allocate a new canvas when its signature changes (the stale-texture fix).
- Because it sits in `getGradedImage`, all four composition paths (flat, 2D device, 3D, Surface) and every export get it. Known gaps left as they are: auto-layout and Set-mode's plain fallback draw raw `state.image` (pre-existing, also skip temp/tint and Bokeh); note in CLAUDE.md.

### UI: `src/features/color-tools-ui.js` (`bindColorTools()`, `// v38`)
- New `.sidebar-section` "Curves & Levels" in `editor/index.html`, `data-group="adjust"`, no `data-simple` (Pro only), placed after the Bokeh section.
- Channel tabs RGB / R / G / B (real `<button>`s with titles).
- Curve editor: a 256x256 canvas with a faint luminance or channel histogram (computed from the base `ImageData` the hook already caches), grid, the curve, and points. Pointer events: click adds a point, drag moves it, double-click or drag off the box removes it (end points stay). `saveStateToHistory()` on pointerdown, rAF-throttled `render()` while dragging, final render on pointerup.
- Levels: black / gamma / white sliders per channel, following `bokeh-ui.js` `slider()` (label on `input`, save + render on `change`).
- "Reset channel" and "Reset all" buttons (`showUndoToast` on Reset all).
- Element ids in `src/ui/elements.js`; `refreshColorToolsUI()` called from `updateUIFromState()` and via `onHistoryChange(() => queueMicrotask(refreshColorToolsUI))`.

### Looks: `src/features/looks.js` (`bindLooks()`, `// v38`)
- Store `glint_looks`, modeled on `palettes.js`: `loadAll`/`persist` with quota toast, ids `'look_' + Date.now().toString(36) + '_' + seq`, `MAX = 60`, `escapeHtml` for names.
- A look = `{ id, name, imageFilters, colorTools }` (Color Map left out: it depends on the palette library).
- Four built-in starter looks defined as curves + filters (for example Matte, Cool Night, Warm Film, Hard Contrast), shown first and not deletable.
- Inside the Curves & Levels section: a Looks row of chips (apply on click, small delete on user looks), "Save look" (name prompt), "Export" (downloads `<name>.glintlook` through `motion-export.js` `download(blob, filename)`), "Copy code" (clipboard with `encodeLook`), "Import" (file via the `merge-studio.js` `FileReader.readAsText` pattern, or pasted code; both through `decodeLook`).
- Applying = one `saveStateToHistory()`, replace `state.imageFilters` + `state.colorTools`, `updateUIFromState()`, `render()`.

### Palette
`registerCommands()` in `palette.js`: `color-tools-open` (reveal section via `studio-nav.js` `revealSection`), `color-tools-reset`, `look-save`, `look-import`, `look-copy-code`. No new global shortcut.
